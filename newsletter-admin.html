📧 DetectLab — Newsletter Admin

Vezi cine este abonat și cine nu (profiles.newsletter_subscribed), filtrează după status și trimite primul newsletter. Necesită autentificare + cheie admin (x-admin-key = INGESTION_ADMIN_KEY / NEWSLETTER_ADMIN_KEY). Backend-ul este singurul scriitor care diferențiază corect audiența — checkbox-ul din formularul de înregistrare scrie direct în public.profiles.

🔐 Autentificare

Loghează-te cu un cont DetectLab, apoi introdu cheia admin dacă backend-ul este configurat cu INGESTION_ADMIN_KEY. În dev fără cheie, orice cont autentificat poate lista / trimite.

Neautentificat
Cheia nu este stocată pe server — rămâne doar în browser pentru acest tab (sessionStorage).
